In-progress library system. Goal of finished project is a database managemant system designed to store a library's members and books, as well as any book loans and related useful information. Users will be able to check-out books and the database logic is automatically updated based on check-outs and check-ins, and the logic will refuse any book loans according to the set policies (e.x. user can't check-out a book if they have an overdue book loan).

Right now the inital java logic and JUnit tests are implemented. Next step is implementing a database and connecting it with the java logic.
